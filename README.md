# Medical-Chatbot-LLM-based
RAG + AWS CI/CD

Built a retrieval-augmented generation (RAG) medical
chatbot using LangChain, Pinecone, and Hugging Face embeddings to ground LLM responses in a 637-page medical
encyclopedia, mitigating hallucinations and improving factual accuracy. Developed the data processing and web
application stack, including PDF text extraction, recursive text chunking, and a Flask-based UI to enable reliable
ingestion, semantic search, and natural language generation. Containerized and deployed the system on AWS using
Docker with EC2 and ECR, and implemented an automated CI/CD pipeline using GitHub Actions.
